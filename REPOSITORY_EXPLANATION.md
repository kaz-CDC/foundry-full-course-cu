# Repository Explanation: Foundry Full Course CU

## Overview

This repository is the **official companion resource** for the **Cyfrin Updraft Blockchain Developer Career Path** - a comprehensive educational course teaching smart contract development using Solidity and the Foundry framework. The course is created by Patrick Collins and powered by Cyfrin.

**Course Title:** Blockchain Developer, Smart Contract, & Solidity Career Path - Powered By AI - Beginner to Expert Course | Foundry Edition 2024

## Purpose

This repository serves several key purposes:

1. **Course Materials Hub** - Houses all resources, code references, and documentation for students taking the course
2. **Community Discussion Forum** - Provides a place for students to ask questions and get help via GitHub Discussions
3. **Updates & Errata** - Documents corrections, updates, and changes to course content over time
4. **Learning Resources** - Contains guides on how to ask/answer questions, use AI prompts, and contribute to open source

## Course Content Covered

The repository supports multiple courses within the Cyfrin Updraft platform:

### 1. Blockchain Basics
- Introduction to blockchain technology fundamentals

### 2. Solidity 101 (4 Sections)
- **Section 1: Simple Storage** - First smart contract, basic Solidity types, functions, arrays, structs, mappings
- **Section 2: Storage Factory** - Importing contracts, contract interactions, inheritance
- **Section 3: Fund Me** - Sending ETH, Chainlink oracles, libraries, modifiers
- **Section 4: AI Prompting** - Using AI tools effectively, asking questions, GitHub setup

### 3. Foundry Fundamentals (4 Sections)
- **Section 1: Simple Storage** - Local development setup, Foundry installation, deployment
- **Section 2: Fund Me** - Testing, deploy scripts, mocking, coverage
- **Section 3: HTML/JS Fund Me** - Frontend basics, MetaMask integration
- **Section 4: Smart Contract Lottery** - Chainlink VRF, Automation, comprehensive testing

### 4. Advanced Foundry (6 Sections)
- **Section 1: ERC20s** - Token standards and implementation
- **Section 2: NFTs/MoodNFT** - NFT creation, IPFS, SVGs, EVM encoding
- **Section 3: DeFi Stablecoin** - The "pinnacle project" covering DeFi concepts, invariant testing
- **Section 4: Cross-Chain Rebase Token** - Cross-chain development
- **Section 5: Merkle Airdrop & Signatures** - Cryptographic proofs, ECDSA signatures
- **Section 6: Upgrades** - Proxy patterns, UUPS upgradeable contracts
- Additional sections on DAOs, Security, and Assembly

## Key Technologies Covered

- **Solidity** - Smart contract programming language
- **Foundry** - Modern Ethereum development framework (Forge, Cast, Anvil, Chisel)
- **Chainlink** - Oracle network for price feeds, VRF, and Automation
- **OpenZeppelin** - Secure smart contract libraries
- **IPFS** - Decentralized storage
- **Ethereum/EVM** - Primary blockchain platform
- **ZKsync** - Layer 2 scaling solution (optional advanced content)
